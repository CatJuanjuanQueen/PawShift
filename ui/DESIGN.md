# PawShift 小狗工作搭子 UI

以参考小狗的立耳、炭黑毛色、奶油色眉毛与脸颊、蓝色项圈为品牌特征。整体采用安静、温暖的桌面工作台风格，小狗出现在品牌标识、欢迎区、侧栏和空状态中。

## 视觉规则

| 用途       | 浅色主题           | 深色主题           |
| ---------- | ------------------ | ------------------ |
| 工作区底色 | `#FAF9F5` 奶油白   | `#242622` 暖炭黑   |
| 卡片       | `#FFFEFA`          | `#2C2F28`          |
| 主文字     | `#34352F`          | `#EEEAE0`          |
| 主按钮     | `#286879` 项圈蓝   | `#9BCBD8` 浅项圈蓝 |
| 欢迎区     | `#E8F0EB` 鼠尾草绿 | `#343F33`          |

- 卡片圆角 16px，按钮与输入框圆角 10px；边框轻、阴影弱。
- 导航采用统一圆端线条图标；状态同时包含文字和颜色。
- 队列依次呈现欢迎区、状态统计、调度操作、搜索筛选和任务列表。
- 主操作使用项圈蓝；停止操作采用低强调的红色文字。
- 三步任务表单保留字段说明与草稿逻辑，统一卡片、表单和步骤样式。
- 支持浅色、深色、跟随系统、键盘焦点、减少动态效果和窄窗口。

## 可编辑素材与导出

- `ui/brand.svg`：小狗头像应用标识，透明边缘、奶油色圆角背景。
- `ui/dog.svg`：透明背景坐姿小狗，保留蓝色项圈和胸前浅色毛。
- `ui/icon.png`：256px 桌面和托盘图标。
- `ui/icon.ico`：16、24、32、48、64、128、256px Windows 图标。
- `ui/app.js` 中的 `glyphs`：统一的功能图标路径，使用安全的 SVG DOM 构建。
- 修改品牌 SVG 后运行 `node scripts/export-icons.cjs` 重新导出 PNG/ICO。
- 所有视觉资源都随程序打包，无需在线字体或外部图片。
